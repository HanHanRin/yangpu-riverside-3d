# 时间之岸｜杨浦滨江 3D 城市切片

## 在线体验

- 网页：https://hanhanrin.github.io/yangpu-riverside-3d/
- 源码：https://github.com/HanHanRin/yangpu-riverside-3d
- 原始项目：`Kimi_Agent_杨浦滨江3D城市切片.zip`。
- `main` 保存源代码，`gh-pages` 保存 `npm run build` 生成的网页文件，GitHub Pages 从 `gh-pages` 分支根目录发布。
- 后续更新网页时，先运行 `npm ci && npm run build`，再将 `dist/` 内容同步到 `gh-pages` 分支。

## 内容

- 1915、1955、1995、2015、2026 五个年代断面。
- 10 处滨江地标，包含“瑞镕船厂／上海船厂—抖音集团上海滨江中心”的同址变迁。
- 真实黄浦江水面边界、岸线、道路和 1,289 个现状建筑轮廓；2026 年保留全部轮廓，10 处重点地标以特征化模型替换对应体块。
- 377 个 OSM 地表面，区分绿地、运动场地、硬化空间、建设工地、工业、居住与商业地表，并补充道路及滨江绿化。
- 2026 年叠加高德当前公开卫星影像，已从 GCJ-02 逐像素纠偏重采样至 WGS84，并作低饱和处理；地表分类面也保留影像细节。22 处真实 OSM 运动场地增加外轮廓、中心线及大场地中心圆。
- 针对 OSM 缺失的次要现状建筑，在中国节能·上海首座、杨浦滨江创智中心、美团上海科技中心、哔哩哔哩新世代产业园和中交滨江广场周边补充 24 个白色体块；依据为影像屋顶与阴影以及 2026 年政府公开建设进展。历史年代不使用当代影像或这些补充体块。
- 2026 年“工作生活圈”以抖音集团上海滨江中心为原点，增加 20 处商业、公园、运动活动与文化设施，支持独立开关、分类筛选、直线距离查看与近景定位。
- 公园绿地增加透明绿色地表与 605 株树木；运动场地、活动平台增加色彩和简化设施；真实 OSM 步行道与骑行道分色显示；商场、书苑等保留真实建筑轮廓并突出边界。
- 沿真实道路和步道运动的车流、行人，分别提供独立开关；五个年代使用不同密度。
- 支持旋转缩放、地标定位、五步同址演变、年代播放、自动演示，以及历史年代与 2026 年的同步分屏对比。
- “滨江地标”和“工作生活圈”面板可拖动，拖动不会误触展开／收起；两个面板展开互斥，避免列表互相遮挡。顶部“自动演示”使用高亮主按钮，并同步显示播放状态。

## 数据与模型边界

底图快照来自 OpenStreetMap／Overpass API，时间为 2026-10-26，许可为 ODbL 1.0。所有地图与地标使用同一经纬度投影和真实坐标锚点。

- 水面、岸线、道路、现状建筑平面轮廓，以及 `landuse`、`leisure`、`natural`、`landcover`、`amenity`、步行区域等来自 OSM。
- 地标以现状轮廓中心和最长边校正位置、朝向，并做主体水面碰撞检查；绿之丘按单体轮廓收紧占地。船坞和水厂栈桥作为真实跨水设施保留，不按普通建筑强制移上岸。
- 树木避开 OSM 水面、建筑轮廓和地标边缘缓冲范围。
- 地面、影像、分类地表、场地标线、水面和道路使用独立高度；开启对数深度缓冲并提高相机近裁剪面，水面不写深度，降低掠射角闪面。不同地表类别也有微小高度差。
- 数字标识使用各地标、各年代的主建筑屋顶局部锚点，经实际位置、朝向和尺度变换到世界坐标；引线长度随标签碰撞偏移实时计算，不再使用包含烟囱、船坞和栈桥的整体包围盒。
- 建筑高度优先使用 OSM `height`，其次使用 `building:levels × 3.2`，其余按建筑类型推定。
- 高德公开瓦片检索于 2026-10-27，未提供影像拍摄日期；检索日期不等于拍摄日期，不能据此断定为某一确定日期的测绘成果。影像只用于 2026 现状地表参考。
- 24 个补充体块记录于 `public/data/current-infill.json`，只补充 OSM 缺失的次要现状建筑。高度优先采用公开资料，缺失时按影像阴影与周边尺度推定；白色体块为概模，不是施工模型。
- 工作生活设施记录于 `public/data/worklife.json`。点位优先对应 OSM 建筑、地表与道路，2026 年名称和功能由政府公开资料核对；没有独立 OSM 轮廓的设施仅作点级标识，不表示精确占地或权属。列表距离为工区直线距离，不是步行导航。新增树木、场地色彩与休憩设施是展示性表达，不是园林施工图。
- 为使米级体块在城区尺度可读，背景建筑统一使用 2× 纵向显示倍率；平面轮廓不缩放。
- 历史背景建筑的数量、存续与高度是可视化推演，不是历史测绘。
- 重点地标按公开实景的可识别特征进行程序化概模，不是文保勘察或施工模型。

现代背景高层的复用与公开资料来源见 `CREDITS.md` 及页面“说明”。

## 技术

Three.js + Vite。道路使用真实线几何生成，水面、地表和建筑使用真实面几何；重复窗格、树木、车辆与行人使用实例化，静态建筑按材质与阴影状态合并。车辆和行人沿真实路径累计长度运动，按西、中、东分区更新；场景按需重绘，动效开启时约每 50ms 更新一次，分屏对比共享相机与控制器。数据快照位于 `public/data/yangpu-osm.json`。
